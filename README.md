# Heart Disease Prediction using Machine Learning

Predicted whether a patient has heart disease using two ML models and compared their performance.

## Dataset
Cleveland Heart Disease Dataset — 303 patients, 13 health features

## Algorithms Used
- Random Forest Classifier
- Logistic Regression

## Libraries Used
- pandas
- numpy
- scikit-learn
- matplotlib
- seaborn

## Results
- Best Accuracy: ~85%
- Models compared: Random Forest vs Logistic Regression
- Most important feature: thalach (Maximum Heart Rate)

## How to Run
Open the .ipynb file in Google Colab and click Runtime → Run all
